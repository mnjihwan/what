# what

주제를 탐색하고 작은 기능부터 구현하기 위한 바이브 코딩 작업 공간입니다.

## 현재 상태

- 단계: 아이디어 탐색
- 프로젝트 주제 / 대상 사용자 / 기술 스택: 미정
- 실행 가능한 애플리케이션: 아직 없음

## 문서 안내

| 파일 | 용도 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | AI 코딩 도우미의 작업 원칙 |
| [PROJECT.md](PROJECT.md) | 프로젝트 목표와 최소 기능 범위 |
| [TASKS.md](TASKS.md) | 할 일과 완료 기준 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 기술 구성과 실행 방법 |
| [DECISIONS.md](DECISIONS.md) | 중요한 결정과 그 이유 |
| [HANDOFF.md](HANDOFF.md) | 다음 작업을 위한 현재 상태 |

## 시작 순서

1. PROJECT.md에 해결할 문제와 대상 사용자를 한 문장씩 적습니다.
2. 첫 버전의 핵심 기능을 1~3개 정합니다.
3. 필요한 기술을 고르고 ARCHITECTURE.md에 기록합니다.
4. TASKS.md에서 가장 작은 작업 하나를 골라 구현하고 확인합니다.

## AI에게 요청하는 예시

> AGENTS.md와 프로젝트 문서를 읽고 현재 상태를 파악해줘.
> 이번 목표는 [원하는 결과]야. 완료 기준은 [확인 가능한 동작]이야.
> 필요한 변경을 구현하고 검증 결과와 다음 할 일을 문서에 반영해줘.

## 실행 방법

기술 스택을 선정한 뒤 ARCHITECTURE.md에 설치, 실행, 검증 명령을 기록합니다.
